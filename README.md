# Simon Says Game

A simple and interactive Simon Says Game built using HTML, CSS, and JavaScript. The game challenges players to remember and repeat an increasingly long sequence of colors.

## Features

- Interactive Simon Says gameplay
- Four colored game buttons
- Increasing difficulty with each level
- Game over detection and restart
- Flash animations for game and user inputs
- Dark Mode toggle
- Theme preference saved using localStorage
- Responsive and clean user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How to Play

1. Press any key to start the game.
2. Watch the color sequence carefully.
3. Repeat the sequence by clicking the colored buttons.
4. A new color is added each level.
5. The game ends if you click the wrong button.
6. Use the **Dark Mode** button to switch between light and dark themes.
